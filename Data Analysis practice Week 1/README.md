# Week 1 – Excel & Data Analysis

## 📌 Project Overview

This project is part of my Week 1 Data Analyst course.

The main focus of this week was learning Excel basics, data cleaning, Pivot Tables, descriptive statistics, conditional formatting, and data visualization.

The project uses a sales dataset to analyze sales performance and generate useful insights.

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Conditional Formatting
- Excel Formulas
- Excel Charts

## 📊 Tasks Completed

### 1. Data Cleaning

- Checked the dataset for duplicate records.
- Removed/checked duplicate values.
- Checked for missing values.
- Identified missing values in the Postal Code column.
- Prepared the data for analysis.

### 2. Region-wise Sales Analysis

Created a Pivot Table to summarize sales by region.

**Fields used:**
- Region
- Sales

The Pivot Table uses the **Sum of Sales** to compare sales across different regions.
